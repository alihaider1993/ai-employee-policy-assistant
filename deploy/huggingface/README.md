# Employee policy assistant

Ask questions about the publicly available FCA Employee Handbook. Answers are generated with retrieval-augmented generation (Azure AI Search + Azure OpenAI, orchestrated with LangGraph) and cite the handbook pages they came from.

The page is at `/ui`. The REST API is at `/ask`, documented at `/docs`.

Answers are generated by AI and can be wrong. Questions are stored to cache answers, so don't enter personal information.
